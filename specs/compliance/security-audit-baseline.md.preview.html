Security & Audit Baseline

1. 목적

이 스펙은 이제너두 전사 CRM OS MVP의 컴플라이언스·보안·감사 구현 기준선이다. A1/A2/A4/A6/A8/A9가 RBAC, 테넌트 격리, 개인정보 접근로그, 감사로그, 보존정책, 외감 증적 요구를 구현 또는 검증할 때 사용할 공통 요구사항을 정의한다.

개인정보/민감정보 항목, 처리범위, 보관기간, 외부 전송 항목, 위탁/재위탁, 최종 아키텍처는 본 스펙에서 확정하지 않으며 모두 PM 승인 필요로 둔다.

인당 생산성/마진 기여: 검증 가능한 기준선을 제공해 보안 요구 누락, 감사 증적 재수집, 권한 재작업에 들어가는 반복 인력을 줄인다.

SEC-12 입사등록 승인 게이트 입사등록 최종 승인 전 임직원 계정 활성화와 권한 부여를 완료하지 않는다. 승인 없는 계정 생성과 권한 오부여 재작업을 줄인다.
SEC-13 메뉴별 로그 기본 마스킹 메뉴별 로그는 메뉴 진입, 조회, 수정, 결재, 반출을 기록하고 개인정보 포함 값은 기본 마스킹한다. 메뉴 단위 권한 점검과 장애 조사 시간을 줄인다.

SEC-16 팀 채팅 최소노출 팀 채팅 참여자 선택은 부서, 이름, 권한 표시를 최소화하고 외부/권한 없는 사용자 초대를 차단한다. 협업 속도는 유지하면서 채팅 권한 누락과 감사 조사 비용을 줄인다.

CHAT-03 외부 사용자, 타 테넌트 사용자, 권한 없는 사용자의 초대는 차단한다. 초대 차단은 permission_denied, 행위자, 대상자, 사유로 기록되어야 한다.
CHAT-04 채팅방 생성, 참여자 추가/제거, 메시지 전송, 파일 첨부, 다운로드 시도는 로그 대상이다. chat_room_id, message_id, attachment_id, actor_user_id로 조회 가능해야 한다.
CHAT-05 개인정보·민감정보 포함 메시지와 파일 첨부는 원문 최소 보존, 마스킹, 다운로드 제한 후보로 관리한다. 콘텐츠 위험 분류, 파일 유형/크기, 마스킹 여부, 다운로드 권한, 보존기간 후보가 기록되어야 한다.
CHAT-06 채팅 로그 상세 조회와 반출 요청은 별도 권한과 감사로그를 요구한다. 보안/감사 목적 없는 채팅 로그 조회와 반출은 차단되어야 한다.

인당 생산성/마진 기여: 채팅 협업 속도는 유지하면서 초대 오류, 파일 반출, 개인정보 메시지 조사 비용을 줄인다.
