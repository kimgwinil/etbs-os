# 권한별 메뉴 및 사용자 정보 표시 스펙 초안

## 1. 목적

경영자, 관리자, 일반 직원, 슈퍼바이저가 서로 다른 메뉴와 업무 진행 메뉴를 보도록 하고, 현재 로그인 사용자의 소속, 이름, 권한을 상단 메인 설정 메뉴 옆에 표시한다. 각 메뉴 화면의 오른쪽 상단에 있는 개별 설정 버튼은 중복이므로 제거하고, 설정 진입점은 상단 메인 메뉴의 설정으로 단일화한다.

인당 생산성/마진 기여: 사용자에게 필요한 메뉴만 보여 탐색 시간을 줄이고 민감정보 노출 리스크를 낮춘다.

## 2. 사용자 정보 표시

상단 메인 설정 메뉴 옆에는 다음 정보를 표시한다.

- 소속
- 이름
- 권한명: 일반, 관리자, 슈퍼바이저 등

인당 생산성/마진 기여: 누가 로그인한 화면인지 즉시 확인해 대리 처리와 권한 착오를 줄인다.

## 2.1 설정 메뉴 단일화

- 설정 진입점은 상단 메인 메뉴의 `설정` 하나만 유지한다.
- 각 업무 메뉴, 목록, 상세 화면 오른쪽 상단의 개별 설정 버튼은 제거한다.
- 화면별 필터, 정렬, 컬럼 선택 같은 보기 옵션이 필요하면 `보기 설정` 또는 `필터 저장`으로 분리하고, 시스템 설정처럼 보이는 아이콘/버튼명을 사용하지 않는다.
- 로그기록 확인, 권한 관리, 사용자 정보, 슈퍼바이저 설정은 상단 메인 설정 메뉴 하위에서 접근한다.

인당 생산성/마진 기여: 중복 설정 버튼을 제거해 사용자가 어디에서 설정해야 하는지 혼동하는 시간을 줄이고 화면 밀도를 낮춘다.

## 3. 권한별 메뉴

| 권한 | 표시 메뉴 | 제한 |
|---|---|---|
| 일반 | 내 영업활동, 내 파이프라인, 견적, 주문, 내 결재함 | 전사 영업이익, 전사 로그, 권한관리 접근 제한 |
| 관리자 | 고객, 상품, 주문, 출고, 발행, 팀 업무, 팀 결재 | 산식 변경, 전체 권한관리 제한 |
| 슈퍼바이저 | 전사 대시보드, 영업이익, 설정, 로그, 권한관리 후보 | 개인정보 상세와 비용 입력은 승인된 범위만 접근 |
| 경영자 | 경영 대시보드, 영업이익, 매출인식, 주요 리스크 | 운영 상세 변경 제한 가능 |
| 수익성 비용 입력권한자 | 설정 > 수익성 비용 입력 | 제원원가/판관비/일반관리비 입력 외 권한은 별도 부여 필요 |

인당 생산성/마진 기여: 역할별로 처리 화면과 판단 화면을 분리해 업무 집중도와 통제 수준을 높인다.

## 4. 인수조건

1. 상단 메인 설정 메뉴 옆에 소속, 이름, 권한이 표시되어야 한다.
2. 일반 사용자는 슈퍼바이저 대시보드를 볼 수 없어야 한다.
3. 메뉴 숨김은 UI뿐 아니라 API 권한과 일치해야 한다.
4. 권한 변경 후 다시 로그인하거나 세션 갱신 시 메뉴가 변경되어야 한다.
5. 권한 없는 메뉴 접근 시 차단되고 로그가 남아야 한다.
6. 각 업무 메뉴 오른쪽 상단에는 시스템 설정으로 보이는 개별 설정 버튼이 없어야 한다.
7. 설정 관련 기능은 상단 메인 설정 메뉴에서만 접근 가능해야 한다.
8. 제원원가, 판관비, 일반관리비 입력 화면은 마스터 또는 수익성 비용 입력권한자에게만 보여야 한다.
9. 권한 없는 사용자가 비용 입력 URL 또는 액션에 접근하면 차단되고 로그가 남아야 한다.

인당 생산성/마진 기여: 화면과 API 권한을 일치시켜 보안 재작업과 사고 대응 비용을 줄인다.

- 협업: A7, A8, A9

3. 제원원가/판관비/일반관리비 입력 권한을 마스터 외 별도 권한으로 둘 것인가?
