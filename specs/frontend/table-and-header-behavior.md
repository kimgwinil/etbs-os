# 목록/필드 헤더 UX 스펙 초안

## 1. 목적

모든 목록 화면에서 필드 헤더를 상단에 고정해 사용자가 세로 스크롤 또는 가로 드래그 중에도 필드값의 의미를 알 수 있게 한다.

인당 생산성/마진 기여: 대량 목록 처리 중 컬럼 혼동과 재확인 시간을 줄여 담당자 1인당 처리량을 높인다.

## 2. 적용 화면

- 고객 목록
- 임직원 목록
- 상품 목록
- 영업파이프라인 목록
- 견적/계약 목록
- 주문/출고/배송 목록
- 세금계산서/거래명세표 목록
- 매출인식 목록
- 타임로그/감사로그 목록

인당 생산성/마진 기여: 핵심 운영 목록 전체에 동일 UX를 적용해 화면별 학습 비용을 줄인다.

## 3. 요구사항

- 세로 스크롤 시 컬럼 헤더는 화면 상단에 고정된다.
- 가로 스크롤 또는 드래그 시 현재 컬럼명이 계속 보인다.
- 정렬 가능한 컬럼은 정렬 상태를 표시한다.
- 필터가 적용된 경우 필터 상태를 헤더 또는 상단 영역에 표시한다.
- 모바일 또는 좁은 화면에서는 핵심 컬럼을 우선 고정하고 나머지는 상세 영역으로 이동한다.

인당 생산성/마진 기여: 정렬/필터/고정 헤더가 결합되면 대량 데이터를 빠르게 찾고 처리할 수 있다.

## 4. 인수조건

1. 사용자가 100개 이상 행을 스크롤해도 컬럼 헤더가 보여야 한다.
2. 가로 스크롤이 있는 목록에서 현재 열의 의미를 잃지 않아야 한다.
3. 정렬 적용 여부를 화면에서 식별할 수 있어야 한다.
4. 권한 없는 컬럼은 숨김 처리되고 API에서도 제한되어야 한다.
5. QA는 데스크톱과 iOS 폭에서 헤더 고정을 검증해야 한다.

인당 생산성/마진 기여: QA 기준까지 고정해 화면 구현 후 재작업을 줄인다.
