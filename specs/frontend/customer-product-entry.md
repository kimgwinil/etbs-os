# 고객/상품 등록 UX 스펙 초안

## 1. 목적

고객 등록과 상품 등록 흐름을 명확히 하여 신규 저장, 수정 저장, 판매가격 확인이 즉시 가능하도록 한다.

인당 생산성/마진 기여: 고객/상품 입력 오류와 가격 확인 시간을 줄여 견적과 주문 처리 속도를 높인다.

## 2. 고객 등록

- 고객등록 메뉴에서 신규 등록을 선택한다.
- 필수값 입력 후 저장하면 신규 고객으로 생성된다.
- 저장 성공 시 고객 상세 또는 고객 목록에 반영된다.
- 생성 시 `time_log`를 남긴다.

인당 생산성/마진 기여: 신규 고객 생성 기준을 명확히 해 중복 등록과 후속 정정 시간을 줄인다.

## 3. 고객 수정

- 기존 고객 상세에서 수정한다.
- 저장하면 변경된 고객정보로 간주한다.
- 변경 전후 이력 또는 변경 이벤트는 타임로그/감사로그 대상이다.
- 권한 없는 사용자는 수정 저장을 할 수 없다.

인당 생산성/마진 기여: 변경 기준과 로그를 고정해 고객정보 오류 원인을 빠르게 추적한다.

## 4. 상품 등록 및 판매가격 표시

- 상품 등록 화면에는 판매가격 입력 영역을 별도로 둔다.
- 상품 목록과 상세 화면에는 판매가격을 즉시 볼 수 있는 컬럼 또는 강조 영역을 둔다.
- 견적/주문 생성 시 판매가격을 기본값으로 참조한다.
- 가격 변경은 적용일과 변경 이력을 가져야 한다.

인당 생산성/마진 기여: 판매가격을 별도 표시해 견적 오류와 할인 판단 시간을 줄인다.

## 5. 인수조건

1. 신규 고객 저장 시 신규 고객 레코드가 생성되어야 한다.
2. 고객 수정 저장 시 기존 고객 레코드가 변경되고 로그가 남아야 한다.
3. 상품 등록 화면에서 판매가격이 별도 입력/표시되어야 한다.
4. 상품 목록에서 판매가격을 즉시 확인할 수 있어야 한다.
5. 판매가격 변경은 견적/주문에 미치는 영향을 확인할 수 있어야 한다.

인당 생산성/마진 기여: 인수조건을 저장/가격/로그 기준으로 분리해 운영 오류를 줄인다.
