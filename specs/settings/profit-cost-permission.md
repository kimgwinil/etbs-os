# 수익성 비용 입력 권한 스펙 초안

## 1. 목적

제품원가, 판관비, 일반관리비 기준 설정은 영업이익 산식과 경영 판단에 직접 영향을 주므로 설정 메뉴에서 마스터 또는 별도 입력 권한을 가진 임직원만 수행할 수 있도록 정의한다. 대시보드는 품목별 판매금액과 매입금액을 원천 데이터로 사용하고, 설정 권한자가 정한 비용 기준율을 적용해 영업이익을 자동 산출한다.

인당 생산성/마진 기여: 영업이익 산식을 바꾸는 입력 권한을 제한해 잘못된 비용 입력으로 인한 경영 판단 오류와 재검산 시간을 줄인다.

## 2. 용어

- `제품원가`: 품목별 판매금액에 적용하는 제품 원가 기준율. 실제 회계 용어가 제조원가 또는 상품원가를 의미하는지 확정 필요.
- `판관비`: 판매관리비.
- `일반관리비`: 일반관리비.
- `ProfitCostInputManager`: 수익성 비용 입력 권한을 가진 임직원 후보 권한.
- `Master`: 마스터 또는 슈퍼바이저 상위 권한 후보.

인당 생산성/마진 기여: 용어 미확정을 표시해 잘못된 회계 항목으로 개발되는 재작업을 막는다.

## 3. 입력 가능 항목

| 항목 | 입력 방식 후보 | 적용 범위 후보 |
|---|---|---|
| 제품원가율 | 매출 대비 비율 | 전사, 상품, 고객, 기간 |
| 판관비율 | 매출 대비 비율 | 전사, 상품, 고객, 기간 |
| 일반관리비율 | 매출 대비 비율 | 전사, 상품, 고객, 기간 |

인당 생산성/마진 기여: 비용 입력 범위를 구조화해 상품/고객별 마진 원인을 더 정확히 분해할 수 있다.

## 4. 권한

| 권한 | 입력 | 조회 | 제한 |
|---|---|---|---|
| 일반 | 불가 | 본인 범위 제한 지표 | 비용 입력 화면 접근 불가 |
| 관리자 | 불가 | 팀/업무 범위 지표 | 비용 입력/산식 변경 불가 |
| 슈퍼바이저 | 후보 | 전사 지표 조회 | 입력 가능 여부 PM 승인 필요 |
| Master | 가능 | 전사 지표 조회 | 변경 사유와 로그 필수 |
| ProfitCostInputManager | 가능 | 승인된 범위 조회 | 권한 범위 내 비용 입력만 가능 |
| 감사/재무 | 입력 불가 후보 | 변경 이력 조회 | 입력 권한과 감사 권한 분리 후보 |

인당 생산성/마진 기여: 입력 권한과 조회/감사 권한을 분리해 임의 변경과 검증 충돌을 줄인다.

## 5. 핵심 규칙

- 비용 입력 화면은 상단 메인 설정 메뉴 하위에 둔다.
- 제품원가율, 판관비율, 일반관리비율 설정은 마스터 또는 `ProfitCostInputManager` 권한만 가능하다.
- 품목별 판매금액과 매입금액은 상품/주문/매출 원천 데이터로 보존하고, 대시보드는 이 원천 데이터에 비용 기준율을 적용해 자동 산출한다.
- 입력/수정/삭제 시 변경 사유, 적용일, 적용 범위, 산식 버전을 저장한다.
- 값 변경 전후는 감사로그에 남긴다.
- 권한 없는 사용자의 접근 또는 저장 시도는 차단하고 로그로 남긴다.
- 산식 또는 비용 값 변경이 전사 영업이익에 영향을 주는 경우 결재 대상 후보로 둔다.

인당 생산성/마진 기여: 비용 변경을 권한과 로그로 통제해 영업이익 지표 신뢰도를 유지한다.

## 6. 화면 요구사항

- 설정 메뉴 하위에 `수익성 비용 입력` 메뉴를 둔다.
- 권한 없는 사용자는 메뉴를 볼 수 없거나 접근 시 차단 사유를 본다.
- 입력 화면에는 현재 적용 중인 산식 버전과 마지막 변경자를 표시한다.
- 저장 전 예상 영향 범위와 변경 전후 값을 보여준다.
- 저장 후 영업이익 대시보드의 마지막 갱신 시각과 산식 버전이 갱신되어야 한다.

인당 생산성/마진 기여: 변경 전 영향 범위를 보여줘 잘못된 입력으로 인한 대시보드 왜곡을 줄인다.

## 7. 인수조건

1. 마스터 또는 입력 권한 임직원만 제품원가율, 판관비율, 일반관리비율을 입력/수정/삭제할 수 있어야 한다.
2. 권한 없는 사용자는 비용 입력 메뉴와 저장 액션을 사용할 수 없어야 한다.
3. 비용 입력 변경은 변경 전후 값, 적용일, 적용 범위, 산식 버전, 변경 사유, 변경자를 로그로 남겨야 한다.
4. 비용 입력 변경 후 영업이익 대시보드는 해당 산식 버전을 표시해야 한다.
5. 비용 입력 변경이 결재 대상이면 최종 승인 전 대시보드에 적용되지 않아야 한다.

인당 생산성/마진 기여: 인수조건을 권한과 산식 버전 중심으로 잡아 임의 입력과 수익성 지표 오류를 줄인다.

2. 입력 권한을 `Master`만 허용할 것인가, 별도 `ProfitCostInputManager` 권한도 둘 것인가?
3. 비용 입력 변경을 항상 결재 대상으로 둘 것인가?
