# MVP 인수조건 검증 매트릭스

## 1. 목적

이 매트릭스는 이제너두 전사 CRM OS MVP의 P0/P1 모듈과 핵심 플로우를 QA 관점에서 인수 또는 반려하기 위한 기준표다. 모든 항목은 운영자 처리량, 오류 감소, 회귀 자동화 가능성, 보안/감사 대응성을 기준으로 검증한다.

인당 생산성/마진 기여: 인수조건을 KPI와 직접 연결해 기능 완성이 아니라 운영비 절감 가능성을 기준으로 릴리즈를 판단한다.

## 2. 공통 인수 필드

모든 MVP 스토리는 다음 필드를 포함해야 한다.

| 필드 | 필수 내용 | 누락 시 판단 |
|---|---|---|
| 목적 | 어떤 운영 병목 또는 리스크를 줄이는지 | 반려 |
| 입력 | 사용자 입력, 시스템 이벤트, 외부 연동 입력, 데이터 전제 | 반려 |
| 출력 | 화면 결과, API 응답, 데이터 변경, 로그, 큐 결과 | 반려 |
| 인수조건 | 정상/예외/권한/감사 기준 | 반려 |
| 의존성 | 선행 모듈, 데이터, 연동, 승인 항목 | 조건부 반려 |
| 담당 | 검증 담당과 수정 담당 | 반려 |
| KPI 영향 | 처리량, 오류율, 시간, 문의, 마진 관련 영향 | 반려 |

인당 생산성/마진 기여: 필수 필드 누락을 반려해 개발 완료 후 운영 가치 검증을 다시 하는 낭비를 줄인다.
