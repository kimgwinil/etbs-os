# ETBS OS

ETBS OS는 이제너두 전사 CRM OS MVP를 위한 초기 앱 개발 저장소입니다. 현재 버전은 `Operations Console`, `Profitability Dashboard`, `Security & Audit Baseline`을 바로 확인할 수 있는 정적 프론트 MVP입니다.

## 실행

브라우저에서 `index.html`을 열면 됩니다.

## 현재 범위

- 운영 업무 큐, 검색, 필터, SLA, 일괄 액션
- 업무 상세 패널과 개인정보/감사 로그 UX 기준
- 수익성 대시보드와 운영 콘솔 드릴다운
- 보안 기준선: RBAC, 테넌트 격리, 접근로그, 감사로그

## PM 승인 필요

- 개인정보/민감정보 항목과 처리범위
- 외부 연동별 개인정보 전송 항목
- 보존기간, 파기 방식, 외감 제출 형식
- 인증/인가, 로그 저장소, 암호화 등 아키텍처

인당 생산성/마진 기여: 운영 처리 화면과 수익성 지표를 한 앱에서 검증해 반복 업무 처리량 증가와 저마진 업무 식별을 빠르게 시작합니다.
